# Primera revisión visual

`verify-folder.svg` es una maqueta estática, con datos ficticios claramente identificados. Abrir el SVG en un navegador para revisar la composición a tamaño completo. No es una captura de una ventana implementada y sus controles no ejecutan operaciones.

Adapta DESIGN.md: lateral sereno, configuración superior, resultados dominantes e inspector contextual. La marca es provisional. No incorpora capturas personales, fuentes remotas ni bibliotecas adicionales.

La primera ventana JavaFX incluirá navegación básica y estados vacío/resultados de demostración. Después se conectará el caso de uso mediante un único trabajo en segundo plano, con cancelación confirmada por el motor y cierre controlado. La aprobación y persistencia de identidades siguen siendo requisitos antes de habilitar un flujo completo con referencias personales.

Antes de considerar validada la interfaz: revisar teclado, foco, contraste, escalado y tamaños mínimos en la ventana real. La maqueta no demuestra esos comportamientos.
