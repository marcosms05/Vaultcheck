# Seguridad

Proyecto en desarrollo: ninguna versión está declarada apta para proteger datos reales.

No publicar claves, rutas personales ni detalles de vulnerabilidades explotables en issues públicos. Antes de publicar el repositorio, el responsable debe habilitar el canal privado de avisos de seguridad del proveedor y actualizar este archivo con el enlace. Actualmente no hay canal externo configurado.

Requisitos para una release: verificar dependencias, revisar entradas no confiables y custodia de claves, ejecutar pruebas adversarias y documentar limitaciones y versiones soportadas. El CI inicial solo compila y prueba; todavía no constituye una auditoría ni un análisis completo de dependencias.
